# ADB 设备主页设计文档

## 1. 页面定位

ADB 设备主页是 Android Toolbox 的设备连接、选择和基础操作入口。本文件记录当前 PySide6 桌面程序的设计，不描述 HTML 原型中的演示数据，也不新增尚未实现的功能。

主要职责：

- 查询 ADB Server 中的真实设备，展示设备信息和连接状态。
- 选择全局设备，将 Serial 和 State 同步到命令库、Scrcpy 和状态栏。
- 提供无线连接、设备特权状态检测、ADB Root / Remount 和 Server 基础操作。
- 使用项目随附的终端打开当前设备的交互式 Shell。
- 通过活动日志反馈操作结果；完整任务输出由任务面板展示。

页面不负责命令模板编辑、工作流管理或投屏参数配置；这些内容属于各自的页面。

## 2. 页面入口与整体布局

### 2.1 入口和全局框架

- 左侧导航：`设备 → ADB 设备主页`。
- 程序启动时默认进入主页，并自动查询一次设备列表。
- 页面标题及说明位于“文件 / 设备 / 视图 / 工具 / 帮助”菜单所在顶行，不在页面内容中重复占用一行。
- 标题：`ADB 设备主页`。
- 说明：`连接、刷新并选择当前 ADB 设备；选择结果同步到全局上下文。`
- 顶部工具栏提供刷新、ADB 终端、Scrcpy、原始输出、全局设备选择器和连接状态入口。
- 底部状态栏显示设备连接状态、活动任务数量和当前 Serial。

### 2.2 区域顺序

```text
菜单、页面标题与说明
主工具栏、全局设备选择器、连接状态
┌──────────┬──────────────────────────────┐
│ 左侧导航 │ 当前设备       │ ADB 连接     │
│          ├──────────────────────────────┤
│          │ ADB 特权状态   │ 快捷操作     │
│          ├──────────────────────────────┤
│          │ 设备列表                     │
│          │ 状态及连接限制提示           │
│          ├──────────────────────────────┤
│          │ 活动日志                     │
└──────────┴──────────────────────────────┘
底部状态栏
```

布局约束：

1. 第一行是“当前设备”和“ADB 连接 · 全局上下文”，两栏横向排列。
2. 第二行是“ADB 特权状态 · 按当前设备检测”和“快捷操作”，两栏横向排列。
3. 设备列表位于特权状态区域下方，横跨页面内容宽度。
4. 主页内容中只保留一个 `ADB Root` 按钮，放在特权状态区域；“当前设备”区域不再重复提供 Root 按钮。工具菜单中的 Root 动作仍是全局入口。
5. 活动日志位于主内容下方，通过上下分隔器调整空间；不是设备列表中的一部分。

## 3. 当前设备区域

### 3.1 信息字段

| 字段 | 展示内容 | 未选择或未检测时 |
| --- | --- | --- |
| 型号标题 | 优先显示 Model；Model 缺失时显示 Serial | `未选择设备` |
| Serial | 当前全局设备的 Serial，只读 | 空白 |
| Product / Device / Transport | 展示产品名、设备代号和传输标识 | 字段缺失显示 `—` |
| Android | 通过“获取状态”读取的 Android 版本 | `Android：未检测` |

这里展示的是当前全局设备，不是设备表格中仅被单击选中的行。

### 3.2 操作按钮

| 按钮 | 行为 |
| --- | --- |
| 刷新 | 查询真实设备列表，更新设备表格和全局选择器 |
| 无线连接 | 聚焦右侧无线地址输入框，不自动建立连接 |
| 打开终端 | 校验当前设备在线后，打开内置终端中的交互式 ADB Shell |

## 4. ADB 连接区域

区域标题为 `ADB 连接 · 全局上下文`。全局设备选择器放在主工具栏，这个区域只提供无线地址输入和连接反馈，不再增加第二个设备选择器。

- 输入项：`无线 ADB 地址`。
- 提示示例：`例如 192.168.1.10:5555`。
- 点击“连接”或在输入框中按 Enter，执行 `adb connect <host:port>` 对应的库操作。
- 提交前去除首尾空白；空地址、包含空白字符或不包含 `:` 的地址被拒绝，并写入 WARN 日志。
- 连接任务成功后重新刷新设备列表；连接失败不生成模拟设备。
- 初始反馈：`尚未刷新 ADB Server`。
- 刷新成功后显示 Server 已响应及上次刷新时间。
- 刷新失败时提示查看任务错误输出，并清空失效的设备列表和选择信息。

无线断开由快捷操作和设备表格右键菜单提供。USB 设备不能通过 `adb disconnect` 断开，界面会提示需要拔线。

## 5. ADB 特权状态区域

### 5.1 状态项

| 状态项 | 数据来源 | 显示规则 |
| --- | --- | --- |
| Root | `id -u` | 返回 UID `0` 显示“是”，其他值显示“否” |
| Remount | `/proc/mounts` | 检查 `/`、`/system`、`/vendor` 是否存在 `rw` 挂载，显示“系统分区可写”或“未见可写系统分区” |
| Debuggable | `getprop ro.debuggable` | 展示设备实际返回值 |
| Android 版本 | `getprop ro.build.version.release` | 更新第一行的 Android 字段 |

Root 状态描述的是当前 ADB Shell 的 UID，不代表已检测设备上的所有提权方式。Remount 状态来自挂载信息，不代表执行了 Remount 操作。

### 5.2 操作与限制

| 按钮 | 执行内容 | 前置条件与确认 |
| --- | --- | --- |
| 获取状态 | 读取 UID、Debuggable、Android 版本和挂载信息 | 当前设备必须为 `state=device`；只读取，不自动提权或挂载 |
| ADB Root | 请求当前设备的 adbd 以 Root 模式重启 | 当前设备必须在线；弹窗确认后执行；仅支持的调试构建可成功 |
| ADB Remount | 请求将系统分区重新挂载为可写 | 初始及切换设备后禁用；检测到 Root 后启用；执行前再次确认 |

执行 Root 成功后刷新设备列表；执行 Remount 成功后重新读取特权状态。失败时显示真实错误，不把失败当作权限已经获得。

## 6. 快捷操作区域

| 操作 | 行为 |
| --- | --- |
| 获取 ADB 设备 | 与刷新设备列表使用相同流程 |
| 断开无线设备 | 断开当前无线设备，任务结束后刷新列表；USB 设备只显示提示 |
| 启动 Server | 启动 ADB Server，成功后刷新设备列表 |
| 重启 Server | 先确认可能中断其他程序的 ADB 连接，再依次停止、启动 Server 并刷新列表 |
| ADB 版本 | 查询客户端版本并切换到任务输出查看结果 |

Root、Remount 和 Server 重启都属于可能影响设备或连接的操作，不应在进入主页、选择设备或读取状态时隐式执行。

## 7. 设备列表区域

### 7.1 表格与工具栏

区域标题：`设备列表 · 双击设为当前设备`。

| 列 | 含义 |
| --- | --- |
| Serial | ADB 设备唯一标识或无线连接地址 |
| State | ADB Server 报告的设备状态 |
| Model | 设备型号 |
| Product | 产品名 |
| Device | 设备代号 |
| Transport | Transport ID |

- 表格按整行单选，不允许直接编辑设备信息。
- 保留真实的 `offline`、`unauthorized` 等不可用状态，不只显示在线设备。
- 提示文本同时显示发现设备总数和 `state=device` 的在线数量。
- 工具栏操作：`复制 Serial`、`设为当前设备`、`刷新`。
- 表格设置最小高度，额外垂直空间优先分配给设备列表。

### 7.2 选择与右键行为

- 单击表格行：仅高亮该行，不立即改变全局设备。
- 双击表格行或点击“设为当前设备”：将该行对应 Serial 设置为全局设备。
- “复制 Serial”：优先复制高亮行的 Serial；没有高亮行时使用当前全局设备的 Serial。
- 右键某一行：先选中该行，再显示“复制 Serial”“设为当前设备”“断开无线设备”。
- 右键中的无线断开项只对包含 `:` 的 Serial 启用。

## 8. 全局设备与页面状态

### 8.1 刷新后的选择规则

1. 刷新前的 Serial 仍在列表中：保留该设备，即使它变为离线或未授权状态。
2. 原设备不存在：优先选择列表中的第一台 `state=device` 设备。
3. 没有在线设备但列表非空：选择第一台设备，保留其真实状态。
4. 列表为空：选择器显示“未发现设备”，清空当前 Serial。

刷新和切换选择会重置特权状态及 Android 版本为“未检测”，并禁用 Remount，避免复用旧设备或旧连接的检测结果。状态检测结果返回时，只有其 Serial 仍为当前设备才更新页面。

### 8.2 关键状态与反馈

| 场景 | 界面反馈与行为 |
| --- | --- |
| 首次打开 | 自动发起设备查询；列表提示“正在查询设备” |
| 同一次刷新尚未完成 | 不重复提交设备列表刷新任务 |
| 未发现设备 | 表格为空，全局选择器显示“未发现设备”，连接状态显示未连接 |
| 当前设备在线 | 连接状态显示“设备已连接”，允许通过前置校验执行设备操作 |
| 当前设备离线或未授权 | 继续展示真实 State；Root、Remount、状态读取和终端启动被在线校验拦截 |
| 设备列表刷新失败 | 清除失效设备，提示刷新失败及查看错误输出 |
| 设备命令失败 | 活动日志记录 ERROR；任务输出保留错误内容与任务状态 |

除 Remount 外，部分按钮仍可点击，但执行设备操作前会检查当前 State。校验失败写入 WARN 日志，不伪造执行成功。

## 9. 内置终端入口

点击主页“打开终端”时，直接启动：

```text
tool/terminal-1.25.2733.0/WindowsTerminal.exe
```

- 路径相对项目目录定位，不依赖启动时的工作目录。
- 使用新窗口，标签标题为 `ADB · <Serial>`。
- 终端直接运行 `adb -s <Serial> shell`，不先启动本地 PowerShell 或 CMD。
- 终端程序不从 PATH 查找，也不回退到系统安装的 Windows Terminal 或 `wt.exe`。
- 交互式连接需要 ADB 可执行文件：优先使用 `ADB` 配置，否则采用 `adbutils` 的程序定位结果。
- 当前设备必须为 `state=device`；内置终端缺失、ADB 路径无效或启动失败时写入错误日志。
- 会话固定打开时的 Serial；之后切换全局设备不改变该会话目标。
- 终端以独立进程启动，不纳入工具箱活动任务和历史，也不将交互式输出重定向到任务面板。
- 输入 `exit` 或关闭终端窗口结束会话；关闭工具箱不负责结束这个独立终端会话。

工具栏“ADB 终端”和工具菜单“打开内置 ADB 终端”复用同一入口。该操作不再跳转命令库的 Shell 参数弹窗。

## 10. 活动日志与任务反馈

主页下方显示活动日志，提供：

- `全部 / INFO / OK / WARN / ERROR / VIEW` 级别筛选。
- 自动滚动开关、记录数、清空和收起 / 展开。
- 每条记录包含时间、级别和操作说明，最多保留最近 1000 条记录。
- 收起日志正文后减少底部面板占用，将空间还给主页内容。

日志记录设备选择、刷新结果、任务启动和结束等摘要，不替代任务的完整 stdout / stderr。需要完整输出时，通过原始输出入口查看任务面板。

非交互式 ADB 操作通过后台任务执行，避免把设备请求直接阻塞在界面线程中。停止或超时不能强制中断已经发出的 `adbutils` 请求，任务等待当前请求返回后记录最终状态；不在主页承诺即时终止设备操作。

## 11. 视觉、缩放与持久化

- 使用 PySide6、浅色界面；可用时采用 `windows11` 原生样式，字体为 Microsoft YaHei UI。
- 信息和操作通过分组框组织；连接按钮使用主要操作样式，特权状态通过标签展示。
- 两组双栏保持一致的左右结构；设备列表全宽排列在其下方。
- 主页内容使用可滚动区域，窗口高度不足时向下滚动访问设备列表；表格自身可滚动查看行和列。
- 主窗口当前最小尺寸为 `980 × 650`；日志面板和主内容之间可以调整上下空间。
- 保存工作区记录窗口几何尺寸和分隔器状态。设备列表、当前设备及特权检测结果来自本次运行的真实查询，不作为离线设备缓存保存。

## 12. 设计核对清单

- [ ] 主页内容中只有一个 ADB Root 按钮，且位于特权状态区域。
- [ ] 设备列表始终排在特权状态与快捷操作下方。
- [ ] 高亮设备行与全局当前设备的概念区分清楚。
- [ ] 刷新保留已有 Serial；设备消失时按在线优先规则重新选择。
- [ ] 切换或刷新设备后不显示旧的特权检测结果。
- [ ] 无设备、离线、未授权和刷新失败都有明确反馈。
- [ ] Root、Remount、Server 重启执行前要求确认，取消后不执行操作。
- [ ] “打开终端”启动项目内置终端并绑定当前 Serial，无外部终端回退。
- [ ] 窄窗口可滚动访问设备列表，日志收起后释放内容空间。
- [ ] 操作反馈来自真实任务，活动日志和完整任务输出职责分离。
